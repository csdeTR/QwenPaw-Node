QwenPaw 的第三方 Android 客户端。应用安装在手机上，直接连接你自己机器上运行的 QwenPaw，数据不经过任何第三方服务。技术栈为 Kotlin 与 Jetpack Compose。

本项目为非官方项目，由第三方独立开发，与 QwenPaw 的开发团队没有隶属关系。QwenPaw 的名称与标识归其所有者，此处仅用于说明用途。

## 快速开始

**前提**：一台已经运行 QwenPaw 的机器，且手机能够访问它。服务端要监听手机可达的地址（`--host 0.0.0.0` 或某个局域网 IP）；也可以只监听 `127.0.0.1`，再经由反向代理或内网穿透暴露出来。监听回环地址又没有做转发时，手机无法连接。

**下载**：安装包在 [Releases](https://github.com/csdeTR/QwenPaw-Node/releases)。每版有两种语音变体，各自按 CPU 架构分四个，共八个包：

- **标准包**：本地识别与服务端转写二选一，默认本地识别（模型约 150MB，按需下载）。
- **`-no-sherpa` 包**：只有服务端转写，安装包约 7–8MB。

两个变体包名相同，可互相覆盖升级，但不能同时安装。架构选 `arm64-v8a` 即可覆盖 2019 年之后发布的绝大多数手机；`x86_64` 用于模拟器。系统要求 Android 8.0 及以上。变体的差别见[使用手册第 4 节](docs/guide.md)，装错架构的表现见第 7 节。

**首次连接**：启动后进入三步引导：填写服务器地址并验证、选择登录方式（扫码登录优先，也可用账号密码；服务端未开登录时自动跳过）、选择一个智能体。三步都完成才能进入主界面。扫码登录需要 Web 控制台的「设备配对」生成的二维码，依赖配套插件 0.4.3 及以上。

完整的连接流程、多地址与反向代理配置见[使用手册第 1 节](docs/guide.md)。

## 功能概览

- **对话**：列表、新建、重命名、删除、置顶、归档与批量操作；按时间、来源或不分组三种排序，可按频道筛选、自建分组、为单个对话设置图标。
- **消息与渲染**：SSE 流式输出、Markdown 渲染、代码块复制、LaTeX 公式与上下标；思考过程、工具调用与中间回复可三档折叠。每条消息可复制或查看 Markdown 原文。
- **输入**：附件多选、`/` 斜杠命令、语音输入、模型切换、思考强度调节、全屏输入。
- **智能体协作**：工具调用审批、收件箱未读汇总、定时任务执行记录、会话全文检索（需配套插件）。
- **服务端管理**：用量统计、模型与提供商、技能、MCP、扩展市场、环境变量、工具执行方式、工作区目录、运行日志。
- **工作区与开发**：文件浏览、预览、下载、上传与文本编辑；默认终端、Bridge 中继（需配套插件 v0.4.0）与 SSH 直连，对话列表顶部可直接进入，多标签、标签改名、shell 选择、缩放与键栏，后台运行时通知栏常驻会话并可停止，切换服务器实例前会确认；Git 改动、暂存、提交与历史。
- **多实例**：可保存多个服务端，单个实例也能配多个地址并按网络自动切换。

逐项的使用说明见[使用手册](docs/guide.md)，界面结构与交互细节也在其中。

## 版本路线

项目的目标是让手机尽可能替代 Web 控制台，做到随处可用。能在手机上完成的功能会直接做。更适合在 Web 控制台完成的操作，手机端保留入口，并在进入前提示；高危操作仍会要求二次确认。已发布的版本见 [Releases](https://github.com/csdeTR/QwenPaw-Node/releases) 与[变更记录](CHANGELOG.md)。以下是后续计划，版本与内容可能调整。

| 版本 | 主题 | 主要变化 |
|---|---|---|
| 0.7.4 | 完整管理面与 Git 写操作 | 模型与提供商增删改及授权、频道配置、技能池管理与自动化、访问控制完整名单、技能配置；Git 换分支、丢弃改动与反向提交，均带影响预览与确认 |
| 0.7.5 | 安全加固 | 图片跨源凭据、存储降级、二维码校验、受信任地址两侧配置与 Bridge 敏感端点收紧；配套插件 0.5.1 提供国际化基础与发布校验和 |
| 0.7.6 | 功能面补全 | 语音与工作区设置、技能池单技能配置与 URL 导入、头像、记忆、社区等剩余上游能力；按优先级分批 |
| 1.0.0 | 前端重写 | 单套新界面；HyperOS 超级岛 |
| 1.0.1 | English 语言支持 | 全量英文界面，首屏与设置页可选择简体中文或 English；不改变页面结构 |

1.0.0 的前端重写只做一套新界面，原计划同时提供的经典与 OpenClaw Node 风格已取消：同时维护多套 UI 没有实际使用场景，只会增加排版与文案的维护成本。

配套插件（Bridge）独立发版，承担检索、事件流、推送、SSH、设备配对与浏览器诊断等能力；0.4.3 起提供令牌签发与吊销，0.5.0 起提供浏览器诊断的日志与修复，0.5.1 起提供受信任地址、按来源网段收紧敏感端点与国际化基础。

**浏览器诊断的限制**：Chrome 扩展要求 QwenPaw 与 Chrome 在同一台机器，并且服务监听本机地址。远程服务器或云端只能显示诊断状态，不能安装或修复扩展。

## 功能边界

以下为当前版本的限制；后续版本会把其中一部分搬进手机，见上方的「版本路线」。

- **服务端管理的一部分留在 Web 控制台**：服务端日志、安全规则 JSON 编辑、MCP 访问主体规则表、技能池单技能配置等深度管理项。技能池分发、MCP 连接参数与 OAuth、扩展市场安装已在手机端提供。设置里的「运行日志」记录的是手机上的客户端事件，不是服务端日志。
- **受信任地址需要两侧配置**：App 与 Bridge 都添加同一地址后，Bridge 才会下发 SSH 凭据等敏感内容；域名或非内网来源还需在 Bridge 填写来源网段。私有网段与组网网段不受影响。
- **离线不自动补发**：断网时草稿保留，恢复网络后需手动点「重试」。
- **审批状态靠轮询**：每 2.5 秒一次，没有推送通道。
- **不支持 Mermaid**：代码块中的图表以源码显示。
- **Platform 与魔搭创空间的实例不可直连**：平台不对外提供端点，用内网穿透转发违反其使用规则，因此填地址时即拦截。官方客户端的 Platform 支持走的是平台自己的 OAuth 授权，与自建实例直连不是一回事。
- **只适配小米、红米的 HyperOS 超级岛，不适配「实况窗」「原子岛」「流体云」等。** 其他平台同类能力的适配，在以下事件发生其一后才开始：
  1. 太阳从东边落下。
  2. csdeTR 不再游玩《原神》。
  3. 「鸡吃完了米，狗舔完了面，火烧断了锁」
  4. 华为、vivo、OPPO 寄来设备，供「实况窗」「原子岛」「流体云」的测试临时使用，且不需要 csdeTR 承担包括往返运费在内的任何费用，不会介意适配之余观察它们运行《原神》时的效率。

## 国际化

客户端支持界面语言选择，界面文案全部放在资源文件中。此前「不做国际化」的说明已不再适用。

目前只提供简体中文；English 计划在 1.0.1 加入（见「版本路线」）。简体中文由作者维护；其他语言在加入后由 LLM 翻译与维护，不保证术语与措辞完全一致。

语言选择入口在「设置 → 个人资料与外观 → 外观 → 应用界面语言」；全新安装首次启动时也会先要求选择。

## 常见问题

**无法连接。** 确认端口，再确认服务端监听的是手机可达的地址，或者已经通过反向代理、内网穿透暴露出来。配置了多个地址时，「验证连接」会按顺序尝试并说明最终用的是哪一条。

**滑动不顺畅。** 请安装正式版；调试版未做优化，滚动开销约为正式版两倍以上。

**麦克风提示需要下载模型。** 标准包默认本地识别，需先在「设置 → 语音」下载；也可以把转写来源切到服务端，或改用 `-no-sherpa` 包。

**模拟器无法安装。** 请下载 `x86_64` 的包，`arm64-v8a` 只能装在 ARM 设备上。


其余问题见[使用手册的常见问题一节](docs/guide.md)。

## 开发

```bash
./gradlew :app:installFullDebug          # 编译并安装标准包到已连接设备
./gradlew :app:testFullDebugUnitTest     # 运行 JVM 单测
```

改动代码前建议先读 [AGENTS.md](AGENTS.md)，其中记录了本机的资源硬约束、服务端与设备的使用判据与提交门禁。
