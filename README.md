# QwenPaw Node

> 因为菜狗csdeTR近乎完全没有开发经验，整个仓库都由dsv4.1 flash编码，对于收到的议题和合并请求，我也只能交给llm处理，如果你有优化或修改的想法，推荐直接fork仓库进行二次开发

> 同时，agentscope已经计划为qwenpaw开发配套的移动客户端，在官方移动端可用时，qwenpaw node将会eol，希望各位感兴趣的开发者优先关注官方的qwenpaw仓库，在那边的提交才能被更好的看见和处理，帮助到更多人

QwenPaw 的第三方 Android 客户端。应用安装在手机上，直接连接你自己机器上运行的 QwenPaw，
数据不经过任何第三方服务。

本项目为非官方项目，由第三方独立开发，与 QwenPaw 的开发团队没有隶属关系。
QwenPaw 的名称与标识归其所有者，此处仅用于说明用途。

技术栈为 Kotlin 与 Jetpack Compose，连接你自己部署的 QwenPaw 服务端。

本项目将停止维护（EOL）**，不再接受功能新增，仅保留仓库供查阅。
在此之前仍照常维护，服务端接口若有变动会跟进适配。

## 使用前提

需要一台已经运行 QwenPaw 的机器，手机能够访问这台机器。多数情况下两者处于同一网络；
也可以填写公网域名，此时默认按 https 连接。

服务端应监听在手机能够访问的地址上，启动时加上 `--host 0.0.0.0`。
若只监听 `127.0.0.1`，手机无法连接。

## 下载与安装

安装包发布在 [Releases](https://github.com/csdeTR/QwenPaw-Node/releases) 页面，
按 CPU 架构分成四个。下载与自己设备架构对应的那一个。

- 系统要求 Android 8.0 及以上。
- **经过测试的架构：`arm64-v8a` 与 `x86_64`。** 前者覆盖 2019 年之后发布的绝大多数手机，
  此前多轮均在真机上完成安装、启动、连接与对话验证；后者用于模拟器，
  在同一套流程上验证过。两者都是正式推荐的安装包。
- **额外构建、未经验证的架构：`armeabi-v7a` 与 `x86`。** 这两者仅为尽可能覆盖旧设备
  与旧模拟器而构建，仅确认可以编译产出，**没有可用的设备做过实测**，
  不保证能够安装或正常运行。遇到问题请改用 `arm64-v8a`。
- 调试版与正式版的签名不同。若此前安装过调试版，需先卸载再安装正式版。

不清楚自己设备属于哪种架构时，一般选 `arm64-v8a`：2019 年之后发布的手机基本都是它。
`armeabi-v7a` 只对应 32 位系统的老设备。

## 第一次连接

首次启动会进入三步引导，每步只做一件事。当前这一步没有完成时，「下一步」是灰色的。

1. 填写服务器地址（带端口，例如 `192.168.1.10:8088`）、服务器名称，
   以及这条地址的别名。点「验证连接」通过后才能继续。
2. 填写用户名与密码。服务端未开启登录验证时会自动跳过这一步。
3. 从列表中选择一个智能体。读不到列表时可以在底部手动填写 ID。

用户名和密码默认无需填写，仅在服务端启用了 Web 登录认证时才需要。

详细步骤与常见问题见 [使用手册](docs/guide.md)。

## 功能概览

- **会话管理**：列表、新建、重命名、删除、置顶、归档与批量操作。
  列表支持按时间、按来源、不分组三种方式切换，置顶会话始终排在最前。
  按来源模式下分组可以折叠，也可以新建、改名与删除自建分组。
- **流式对话**：SSE 实时输出，Markdown 渲染，代码块可复制。
  每条消息头部两行显示昵称与完整时刻，下方提供「复制」与「复制为 Markdown」。
  长按消息弹出「复制／复制为 Markdown／选择文本」三项。
- **头像与昵称**：可为自己与智能体各设一张头像，静态图带裁剪，GIF 动图原样保存并循环播放；
  自己的昵称显示在发出的消息头部。
- **消息折叠**：思考过程、工具调用与中间回复支持三档折叠，默认只保留最终结果。
- **附件**：可收发图片，全屏查看支持双指缩放，也可上传文件。
  智能体通过工具交付的文件会以卡片列出，带缩略图、文件名、路径与「已发送」。
- **审批**：工具调用需要确认时，应用内弹出卡片，可直接允许或拒绝。
  审批模式本身也可在聊天页调整，共四档。
- **模型切换**：可在聊天页为当前会话换模型，点输入框上方的模型名即可弹出选择框。
- **工作区目录**：可在聊天页修改智能体读写文件的服务端目录。
- **连接状态**：顶栏显示「已通过「别名」连接至 QwenPaw」「正在生成」「正在连接…」
  或「连接中断，点击重连」。网络恢复后自动重新载入，会话列表也支持下拉刷新。
- **语音输入**：本地识别，音频不出手机，模型按需下载。
- **用量**：上下文占用明细，token 用量统计；可开启在每轮回复末尾显示本轮输入输出。
- **运行日志**：可记录本次运行期间的客户端事件，支持按类别筛选、查看、导出与导入。
  默认关闭。
- **外观**：深浅色主题、界面与聊天字号分别调整、紧凑列表、MiSans 字体。
- **多实例**：可保存多个服务端地址并随时切换。单个实例也能配置多个地址，
  每个地址可起别名并指定使用时机（VPN 时优先、某 WiFi 下优先），
  前一个连不上时自动尝试下一个。默认地址还能临时指定，只对本次打开生效。

## 功能边界

以下能力本客户端不提供，提前说明可避免无效查找。

- **服务端管理功能**：供应商配置、技能管理、服务端日志查看需在 QwenPaw 的 Web 控制台中操作。
  设置里的「运行日志」记录的是手机上的客户端事件，不是服务端日志。
- **离线自动补发**：断网时草稿会保留，但恢复网络后不会自动重发，需要点击「重试」。
- **实时推送**：审批状态依靠每 2.5 秒一次的轮询获取。
- **Mermaid 图表渲染**：代码块中的图表以源码形式显示。
- **首字耗时**：QwenPaw 服务端不提供该指标，因此不显示。
- **进程终止后的通知**：应用进程被系统清理后，不再发出回复完成通知。
- **AgentScope Platform 与魔搭创空间上的实例**：这两类实例由平台托管，
  平台不对外提供可直连的端点。要用本客户端连接，只能借助 nps 一类内网穿透工具
  把服务转发出来，而这违反平台对托管实例的使用规则。因此客户端在填地址这一步
  就直接拦截，提示改用私有化部署方案。
  这与官方移动端的能力不冲突：官方客户端的 Platform 支持走的是平台自己的
  OAuth 授权流程，不是按自建实例直连。

## 常见问题

**无法连接。** 请先确认端口是否正确，再确认服务端是否以 `--host 0.0.0.0` 启动。
若只监听本机地址，手机无法访问。若配置了多个地址，可以先点「验证连接」，
它会按列表顺序逐个尝试并说明最终用的是哪一条。

**顶栏显示「连接中断」。** 点击这一行即可重新连接。网络恢复后应用也会自行重载，
不必重启。若长时间仍连不上，请检查服务端是否还在运行。

**滑动不顺畅。** 请确认安装的是正式版。调试版未做代码优化，
滚动开销约为正式版的两倍以上，使用调试版时出现卡顿属于预期表现。

**没有麦克风按钮。** 先确认设置中的「显示语音按钮」是打开的，该开关默认开启。
按钮是否显示与模型是否下载无关；模型未下载时按钮仍会出现，点击后提示下载。

**模拟器无法安装。** 请确认下载的是 `x86_64` 架构的包。`arm64-v8a` 的包只能装在
ARM 设备上，x86 模拟器装不上。

更多问题见[使用手册的常见问题一节](docs/guide.md#七常见问题)。
