# QwenPaw Node

> 因为菜狗csdeTR近乎完全没有开发经验，整个仓库都由dsv4.1 flash编码，对于收到的议题和合并请求，我也只能交给llm处理，如果你有优化或修改的想法，推荐直接fork仓库进行二次开发

> 同时，agentscope已经计划为qwenpaw开发配套的移动客户端，在官方移动端可用时，qwenpaw node将会eol，希望各位感兴趣的开发者优先关注官方的qwenpaw仓库，在那边的提交才能被更好的看见和处理，帮助到更多人

QwenPaw 的第三方 Android 客户端。应用安装在手机上，直接连接你自己机器上运行的 QwenPaw，
数据不经过任何第三方服务。技术栈为 Kotlin 与 Jetpack Compose。

本项目为非官方项目，由第三方独立开发，与 QwenPaw 的开发团队没有隶属关系。
QwenPaw 的名称与标识归其所有者，此处仅用于说明用途。

## 快速开始

**前提**：一台已经运行 QwenPaw 的机器，且手机能够访问它。服务端需以
`--host 0.0.0.0` 启动；只监听 `127.0.0.1` 时手机无法连接。

**下载**：安装包在 [Releases](https://github.com/csdeTR/QwenPaw-Node/releases)。
每版有两种语音变体，各自按 CPU 架构分四个，共八个包：

- **标准包**：本地识别与服务端转写二选一，默认本地识别（模型约 150MB，按需下载）。
- **`-no-sherpa` 包**：只有服务端转写，安装包约 2.4MB。

两个变体包名相同，可互相覆盖升级，但不能同时安装。架构选 `arm64-v8a` 即可覆盖
2019 年之后发布的绝大多数手机；`x86_64` 用于模拟器。系统要求 Android 8.0 及以上。
变体的差别见[使用手册第 4 节](docs/guide.md)，装错架构的表现见第 7 节。

**首次连接**：启动后进入三步引导——填写服务器地址并验证、填写账号密码（服务端未开
登录时自动跳过）、选择一个智能体。三步都完成才能进入主界面。

完整的连接流程、多地址与反向代理配置见[使用手册第 1 节](docs/guide.md)。

## 功能概览

- **对话**：列表、新建、重命名、删除、置顶、归档与批量操作；按时间、来源或不分组三种
  排序，可按频道筛选、自建分组、为单个对话设置图标。
- **消息与渲染**：SSE 流式输出、Markdown 渲染、代码块复制、LaTeX 公式与上下标；
  思考过程、工具调用与中间回复可三档折叠。每条消息可复制或查看 Markdown 原文。
- **输入**：附件多选、`/` 斜杠命令、语音输入、模型切换、思考强度调节、全屏输入。
- **智能体协作**：工具调用审批、收件箱未读汇总、定时任务执行记录、会话全文检索
  （需配套插件）。
- **服务端管理**：用量统计、模型与提供商、技能、MCP、扩展市场、环境变量、
  工具执行方式、工作区目录、运行日志。
- **多实例**：可保存多个服务端，单个实例也能配多个地址并按网络自动切换。

逐项的使用说明见[使用手册](docs/guide.md)，界面结构与交互细节也在其中。

## 功能边界

以下能力不提供，提前说明可避免无效查找。

- **服务端管理的一部分留在 Web 控制台**：供应商密钥、服务端日志、技能池分发、
  MCP 的连接参数与 OAuth 授权、扩展市场的安装与下载。设置里的「运行日志」记录的是
  手机上的客户端事件，不是服务端日志。
- **离线不自动补发**：断网时草稿保留，恢复网络后需手动点「重试」。
- **审批状态靠轮询**：每 2.5 秒一次，没有推送通道。
- **不支持 Mermaid**：代码块中的图表以源码显示。
- **Platform 与魔搭创空间的实例不可直连**：平台不对外提供端点，
  用内网穿透转发违反其使用规则，因此填地址时即拦截。官方客户端的 Platform 支持
  走的是平台自己的 OAuth 授权，与自建实例直连不是一回事。

## 常见问题

**无法连接。** 确认端口，再确认服务端以 `--host 0.0.0.0` 启动。配置了多个地址时，
「验证连接」会按顺序尝试并说明最终用的是哪一条。

**滑动不顺畅。** 请安装正式版；调试版未做优化，滚动开销约为正式版两倍以上。

**麦克风提示需要下载模型。** 标准包默认本地识别，需先在「设置 → 语音」下载；
也可以把转写来源切到服务端，或改用 `-no-sherpa` 包。

**模拟器无法安装。** 请下载 `x86_64` 的包，`arm64-v8a` 只能装在 ARM 设备上。

其余问题见[使用手册的常见问题一节](docs/guide.md)。

```bash
./gradlew :app:testFullDebugUnitTest     # 运行 JVM 单测
```

服务端与设备的使用判据、提交门禁；环境操作步骤见 [.agents/test-env.md](.agents/test-env.md)。
