# 使用手册

本手册说明安装完成之后如何使用。关于安装本身，请参考 [README](../README.md)。

内容按实际使用顺序编排：先连接服务端，再认识界面，随后依次说明消息显示、语音输入、字体外观、
头像与运行日志，以及用量。

---

## 1、第一次连接

打开应用后进入连接引导。连接之前，需要有一台已经运行 QwenPaw 的机器。

引导分三步，每步只做一件事。当前这一步没有完成时，底部的「下一步」是灰色的，点不动。

### 第一步：填写服务器

需要填三个字段：

**引导式的第 1 步与「填表添加」是同一套排布**：服务器名称单独在上面，
地址与它的别名收在下面同一个灰框里。两种方式填的是同一批字段，
位置保持一致，换方式时不必重新找一遍输入框。

- **服务器地址**：带端口，例如 `192.168.1.10:8088`。
  只填地址不带协议也能识别：内网地址按 `http://` 尝试，公网域名按 `https://` 尝试。
  如果服务端只能通过 http 访问，请把 `http://` 写全。
  中文输入法容易把句点和冒号打成全角（`。`、`：`），这类输入无需手动修正，
  应用会自动转换为半角。
- **服务器名称**：给这台机器起个名字，例如「家里的机器」。
  之后在实例列表里靠它区分。**可以留空**，留空时实例卡片显示地址。
- **此地址的别名**：可选，例如「局域网」「EasyTier」。
  它只影响这一条地址在列表里的显示，不影响服务器名称。

填好后点击「验证连接」。验证成功之前「下一步」不会变为可点——
地址填了不等于能用，只有确认服务端有响应才算这一步完成。
验证过程中会显示正在尝试第几个地址；若前面的地址不可达，
结果里会写明「已回退到 …」。

结果里同时写明服务端版本与 QwenPaw Node Bridge 的版本。插件未安装时写「未安装」；
服务端开启了登录而这一步还没有凭据时写「未能确认」，保存后可在设置页的「配套插件」行查看。

QwenPaw Node Bridge 是配套插件，提供全文检索与事件推送。安装时在 QwenPaw Web 控制台的
「插件」页粘贴下面这条地址，或在那台机器上执行 `~/.qwenpaw/bin/qwenpaw plugin install <同一地址>`：

```
https://github.com/csdeTR/QwenPaw-Node-Bridge/releases/latest/download/qwenpaw-node-bridge.zip
```

这条地址始终指向最新版。插件在服务端运行时热加载，加载需要数秒，安装后立刻请求可能仍显示未安装。

有两类地址不能添加：源于 AgentScope Platform 的实例，以及通过魔搭创空间创建的实例。
这类地址填写后点击「验证连接」，界面会说明原因并建议使用私有化部署方案，
「下一步」保持不可点。它们的访问依赖平台自己的登录与转发，无法按自建实例的方式连接。

引导页不提供备用地址的填写。多数人只有一个地址，把「备用地址」「回退」
这类概念摆在首次启动的路径上只会让人怀疑自己漏填了什么。
需要配置多个地址时，可以走设置页的「添加实例 → 填表添加」。

### 第二步：账号与密码

这一步会自动检查服务端是否开启了登录认证。

- 未开启时，界面轻提示「该服务端未开启登录验证，已跳过」，随后自动进入第三步。
- 开启时需要填写用户名与密码。

这两项仅在服务端启用了 Web 登录认证（`QWENPAW_AUTH_ENABLED=true`）时才需要。
默认未启用，因此多数情况下这一步一闪而过。

点击「下一步」时会先用这组账号登录一次，成功才进入第三步。
账号或密码不正确时，界面弹出「无法登录」并给出原因，这一页仍停在第二步，
改正后可直接再次点击。这次登录只为核对，不会保存到实例里。

### 第三步：选择智能体

应用会读取这台机器上的智能体列表，从中选中一个即可。
智能体 ID 不需要手动填写；列表读不到时，底部有「手动填写 ID」作为备用入口。

完成三步后点击「完成」，进入聊天页。

### 设置里添加更多实例

设置页的「添加实例」会先让你选择方式：

- **填表添加**：所有字段铺开，可一次配置多个地址与每条的别名、使用时机。
  适合已经熟悉这个应用、想一次改很多项的人。
- **引导式添加**：与首次启动的三步引导完全相同，一步一条。

两种方式连上之后都会在实例列表中出现。

### 填写多个地址

同一台服务端可以同时有局域网地址与隧道地址。在填表方式的「服务器地址」里
点击「添加地址」，把备用地址逐条填进去即可，最多 5 个。

每条地址可以另外填写两项：

- **别名**：显示在实例卡片上的名字，例如「本地」「EasyTier」。
  不填时显示地址本身。
- **使用时机**：不自动切换、VPN 时优先、当前 WiFi 优先。
  命中当前网络的那条会被优先尝试，卡片上会加粗并提示「当前网络正使用这条地址」。

连接失败时，QwenPaw Node 默认依据列表顺序逐一尝试，
便于外出时通过诸如 EasyTier 网络的方式访问 QwenPaw。成功后不会改动顺序。

**「选择地址」里的两种指定方式。** 实例卡片上点击「选择地址」可以手动指定用哪一条：

- 点击某条地址 = **本次使用**。只在本次打开应用期间有效，重启后回到自动选择。
- 「自动选择」= 同时清掉本次指定与长期偏好。

长期偏好需要在「编辑实例」里修改，重启后依然有效。

### 反向代理的访问验证

如果服务端地址前面还有一层 nginx 或 openresty，并且那一层开启了访问验证
（配置里的 `auth_basic`），连接时会被它拦住，表现为 401。
这时在「服务器」这一步展开「反向代理验证（可选）」，填写那一层要求的账号与密码。

- 这与 QwenPaw 自身的登录账号是两套凭据，可以同时使用。
- 两个字段都填写才会生效；只填一项按未启用处理。
- 验证连接时如果被拦住，这一步会自动展开并说明原因，原地填好后再点验证即可。
- 已经连上之后要改，可以在「设置 → 服务器」里编辑该实例，密码留空表示沿用原值。

### 公网地址的安全提示

服务器地址如果可以从广域网访问，而这个服务端又没有开启登录验证、或没有使用 HTTPS，
QwenPaw Node 会在添加服务器时弹一次提示，之后每次启动应用再提醒一次。
提示会说明具体风险与处置办法：前者建议在服务端设置环境变量
`QWENPAW_AUTH_ENABLED=true` 并注册账号，后者建议配置 SSL 证书并把地址改成 `https://`。

不需要这个提醒时，可以在「设置 → 通知与行为 → 安全提示」关闭。关闭时会再确认一次，
因为这个提示描述的是服务端的实际状态，关闭它不会改变任何实际情况。

## 2、界面结构

### 启动后进入聊天页

应用启动后直接进入聊天页，并恢复上次查看的对话。对话列表是独立页面，从左上角进入。

### 对话页

- **搜索**：顶部搜索框按名称过滤，结果在本地计算，不请求服务端。
- **分组**：搜索框右侧的按钮显示当前分组方式，单击在「按时间」「按来源」「不分组」
  之间循环，与 QwenPaw 网页版一致。按时间分为今天、近 7 天、更早三档；
  按来源按服务端已有的对话分组排列。置顶对话在任何模式下都单独排在最前。
  三个服务端内置分组显示为「未分组」「定时任务对话」「子智能体对话」；
  自建分组沿用你自己起的名字。搜索时临时不分组，避免结果被拆到多个表头下。
- **折叠分组**：按来源模式下，点击分组表头即可折叠或展开该组，表头右侧显示该组的
  对话数量。折叠状态会被记住，下次打开应用仍然保持。折叠只收起组内对话，表头仍然可见，
  再点一次即可展开。
- **新建分组**：「按来源」模式下，列表底部有「新建分组」。自建分组刚建好时还没有
  任何对话，因此会以空表头的形式立即出现；长按自建分组的表头可以改名或删除。
  删除分组不会删除组内的对话，它们会回到「未分组」。
- **单项操作**：长按一条对话会弹出菜单，包含重命名、置顶或取消置顶、设置图标、
  **移动到分组**、归档、删除。置顶的对话排在最前，右侧显示图钉标记。
  处于多选模式时长按不会弹出菜单，避免两套操作互相干扰。
  服务端还没有自建分组时，菜单里不出现「移动到分组」。
- **移动到分组**：选择目标分组后对话立刻换到该组表头下。选「未分组」即移回默认分组。
  只有在「按来源」模式下才看得见分组表头，其他模式下移动结果仍会生效，
  切换过去即可确认。
- **对话图标**：每个对话可以单独设一个图标。长按菜单里选「设置图标」，
  可以从 8 个预设里挑一个，或点「从相册选择」用一张图。选图后会进入裁剪页，
  产出的是正方形图片，显示时优先于预设。「恢复默认」回到统一的对话图标。
  紧凑排版下不显示左侧图标，因此这一项在紧凑排版时看不到效果。
- **归档**：归档后对话从列表移除，可在「已归档」页中找到并恢复。
  正在生成回复的对话无法归档，需先停止生成。
  确认框里有「今日不再提示」，勾选后当天不再询问，第二天自动恢复。
- **批量管理**：进入多选模式后可一次归档或删除多个对话。
- **频道筛选**：搜索框下方会出现一行频道选项，首项为「全部」。这一行只在列表里
  出现多于一个频道时显示。选定某个频道后只列出该频道的对话，搜索也在该频道内进行。
  离开列表页再回来会回到「全部」。
- **收件箱入口**：顶栏的铃铛打开收件箱，有未读事件时右上角显示数量。
  收件箱顶部有一行筛选。左侧的来源选项依次为「全部」「定时任务」「心跳」「记忆」
  「技能更新」「邮件」，右侧是智能体选项，默认「全部智能体」。
  两个维度都是单选，可以组合使用，例如同时选「定时任务」与某个智能体。
  筛选生效时只显示符合条件的记录，未读数量也只统计这部分；
  此时「全部已读」不显示，因为它会清除所有来源与所有智能体的未读。
- **全文检索**：分组按钮下方有「全文检索」。服务端已安装配套插件时可用，
  点击后输入关键词，可以搜索全部对话的历史消息，而不只是对话名称。
  结果按对话列出，显示发言角色、时间与命中片段，关键词高亮显示。
  点一条结果会打开对应对话并定位到那条消息。
  未安装配套插件时该入口置灰，并注明「需要配套插件」。
- **下拉刷新**：向下拉动列表即可重新读取对话列表。

### 聊天页

- 顶栏状态行分四种：生成回复时显示「正在生成」；连接正常时显示
  「已通过「别名」连接至 QwenPaw」或「已通过 192.168.1.10:8088 连接至 QwenPaw」；
  正在建立连接时显示「正在连接…」；连不上服务端时显示「连接中断，点击重连」。
  点击这一行会立即重试。若设置过「服务器名称」，正常连接时的末尾会换成该名称，
  例如「已通过「EasyTier」连接至「家里的机器」」；没有设置时仍显示 QwenPaw。
- 输入框右下角是发送按钮。生成回复期间，该按钮变为「停止」。
- 输入框左侧是添加附件按钮。点开后系统先让你选择用哪个应用挑文件，
  可选文件管理器、办公软件、网盘或相册；图片与文档走同一个入口，
  可以一次选多个。选中后逐个上传，其中一个失败不会打断其余。
- 输入框右下角可能出现麦克风按钮。该按钮的显示只由「显示语音按钮」开关决定，
  详见第 4 节。
- 输入框上方的胶囊显示当前对话实际使用的模型名。**点击这个胶囊会弹出模型切换菜单**，
  与右上角菜单里的「切换模型」是同一份列表。
- **向上翻阅历史时**，右下角会浮出「跳到最新」；停在底部时该按钮不出现。
- **斜杠命令**：在输入框的开头键入 `/`，输入框上方会列出可用命令，按分类分组，
  每条都有一句中文说明；继续输入会缩小范围。点选一条会把命令写进输入框，
  并在后面留一个空格，接着就能输入参数。列表只在你从第一个字符开始输入命令时出现；
  命令清单读不到时不提示，直接照常手打即可。
  列表只列面向对话的命令，调试与内部命令不出现；知道名字时直接输入仍然可以执行。

### 新对话的首页

还没发过消息的对话会显示一张首页：智能体头像、一句欢迎语，
以及两条点一下就能发出的预设。头像与设置里的「智能体头像」是同一张，
换过之后这里也会跟着变。

点预设会先问一次「发送这条消息？」，确认后才真正发出。
这样做是因为触屏上误触的代价不低，而这两条会直接建立一个对话。

### 每条消息的排布

聊天页的每条消息都由三部分组成：

```
[头像]  [昵称]
        [2026.10.26 03:38:07]
        ╭──────────╮
        │  气泡内容  │
        ╰──────────╯
        [复制] [复制为 Markdown] [选择文本]
```

- 自己发的消息整体靠右，头像在最右侧；智能体的回复整体靠左，头像在最左侧。
- 消息上方分两行：第一行是发送者昵称，第二行是完整时刻（年月日与时时分秒）。
- 消息下方有三个按钮：「复制」复制纯文本（去掉 Markdown 标记），
  「复制为 Markdown」保留原有格式标记，「选择文本」进入选择态。
  用户消息与智能体消息都有这三个按钮。
  这三个按钮默认显示文字；在设置里可以改为只显示图标（见下一节）。
- 正在生成的那条消息不显示时间与复制按钮，生成结束后才出现。

### 操作行显示文字还是图标

设置中进入「消息显示」，找到「消息操作行」，可选「文字」或「图标」。默认是文字。

改为「图标」后，消息下方三项操作只剩图形，占用宽度更小。两项「复制」的图形很接近，
难以一眼区分，因此长按菜单始终保留文字，需要确认时走长按菜单更稳妥。
无论选哪一档，读屏软件朗读的仍是同一段文字。

### 长按消息

长按气泡会弹出三个选项，不会直接把整段文字塞进剪贴板：

| 选项 | 作用 |
| --- | --- |
| 「复制」 | 复制纯文本，Markdown 标记会被去掉 |
| 「复制为 Markdown」 | 保留 `#`、`**`、表格竖线等原始标记 |
| 「选择文本」 | 询问是否改看原文，选「不显示」时进入选择态 |

选择文本前会先问一次「是否显示 Markdown/LaTeX 原文？」。三个答案的含义：

- **显示**：打开原文页，整条消息的 Markdown 原样铺开，可以拖动选中，也可以点右上角
  「复制全文」。公式、表格、图片在气泡里都是重排过的，看原文才能拿到完整的标记。
- **不显示**：与原来的行为一致，进入选择态。屏幕上看到的就是排版后的结果，
  拖动选到的字符与原文未必逐字对应。
- **取消**：什么都不做。

进入选择态后会出现一条提示，说明「完成选择」在这条消息下方；点它即可回到普通态。
消息底部的「选择文本」按钮与长按菜单里的这一项完全等效。

### 聊天页的更多菜单

右上角三个点展开的菜单里，除了对话本身的操作，还有三项决定「这一轮怎么跑」：

| 菜单项 | 作用 | 形态 |
| --- | --- | --- |
| 「切换模型」 | 为当前对话换一个模型，选「跟随智能体默认」恢复默认 | 居中对话框 |
| 「审批模式」 | 严格、智能、自动、关闭防护四档 | 居中对话框 |
| 「工作区目录」 | 设置智能体读写文件的服务端目录 | 填入框 |
| 「移动到分组」 | 把对话放进某个自建分组，首项「未分组」可移回 | 居中对话框 |
| 「思考强度」 | 调节当前对话的思考开销，只在所选模型支持时出现 | 居中对话框 |

「审批模式」作用于**该智能体的所有对话**，不只是当前对话。
四档的含义分别是：严格（每一步工具调用都要批准）、智能（低风险放行）、
自动（仅受保护的工具需批准）、关闭防护（不再询问）。

「思考强度」只在当前模型支持调节时出现在菜单里，菜单项会同时显示当前取值，
例如「思考强度：跟随默认」。对话框是一条滑块：

- 离散档位型模型（如只提供低、高、最高三档）按档停靠，拖动时逐档跳转。
- 数值预算型模型连续调节，读数是 token 上限，文字随占区间的比例在
  「轻量思考」「均衡思考」「深入思考」「充分思考」之间变化。
- 支持关闭思考的模型，滑块最左一段是「关闭思考」。
- 打开对话框时滑块停在当前实际生效的取值，而不是区间最左端。
- 「恢复默认设置」回到跟随默认。

拖动过程只更新数字与文字，松手才提交，避免每一帧都请求一次服务端。

「工作区目录」填的是服务端上的绝对路径，不是手机上的路径。
设置框里可以随时恢复工作区默认目录。

「分享 Markdown」把整段对话以 Markdown 交给系统分享面板，由你选择用哪个应用处理：
发到聊天工具、存到网盘、发邮件都可以。运行日志的「分享运行日志」走同一条通路。

### 设置页

设置是一级列表，按「服务器」「个人资料与外观」「此手机」「关于」四段排列。
每行右侧的说明就是该项当前的取值，例如「跟随系统 · 字号 100%」「折叠结果 · 用量关」，
不点进去也能确认状态。点击一行进入子页，左上角或系统返回键回到列表，逐层后退。

- **服务器**：实例列表与「添加实例」。添加时先选「填表添加」或「引导式添加」。
  移除实例会先弹出确认框，列出将被清除的配置；本机缓存的离线消息不受影响。
- **我的资料**：头像、昵称、服务端头像开关。
- **外观**：深浅色、界面字号、聊天字号、MiSans 字体。
- **消息显示**：智能体消息折叠、用量显示、消息操作行样式。
- **语音**：语音按钮、触发方式、识别模型。
- **通知与行为**：紧凑排版、生成时保持常亮。
- **运行日志**：记录开关、记录类型、查看与分享。
- **服务端配置**：工具、环境变量、后台策略三项，改的是服务端状态，不是本机偏好。
  「工具」按官方控制台的分组列出服务端已注册的工具，依次为文件与代码、网页与浏览器、
  图像与视频、智能体协作、运行与自动化、应用迁移，每个工具带一个与之对应的线性图标。
  名称与描述均为中文。每个工具一行，右侧的「同步 / 异步」用来选择执行方式：
  同步会等到执行结束，异步则在超时后转到后台继续跑，结果稍后送达。
  关掉的工具不显示这一项。需要参数的工具就地填写，「填写」按钮进入表单。
  「环境变量」分三段常驻显示。「已配置」列出服务端已显式保存的变量，可编辑与删除，
  内置变量只能「恢复默认」。「实时配置」列出每次操作时重新读取的两项超时设置，
  修改后立即生效；改过的项会在「已配置」里同时出现，并标注「实时配置」。
  「只读配置」列出启动时确定、运行期间不能修改的项。点开其中一项，
  可以查看当前值、默认值、来源、说明与修改方式。
  三段的变量值默认以圆点遮罩，点一下显示，离开页面恢复遮罩。
  删除与恢复默认都会先弹出确认框，列出受影响的变量名与当前值。
  列表下方的「添加变量」可以新建自定义变量，填写名称与值后保存：
  名称只能包含字母、数字与下划线，且不能以数字开头；与已有名称重复、
  或属于只读的内置项时，会给出说明而不提交。
  「后台策略」只有一个开关：工具超时后是继续在后台跑完，还是直接中止。
- **关于**：版本号、项目仓库、第三方资源链接。

## 3、消息显示

### 三档折叠

在设置中进入「消息显示」，可配置「智能体消息折叠」，共三个选项：

| 选项 | 效果 |
| --- | --- |
| 全部展开 | 思考过程、工具调用与中间回复全部展开显示 |
| 折叠过程 | 正文按条显示，思考过程和工具调用合并为一组 |
| 折叠结果 | 一个回合只保留最后一条正文，其余内容合并为一组 |

默认选项为「折叠结果」，与 QwenPaw 官方网页的表现一致。

折叠后的分组只显示一行摘要，内容为「处理完成 · N 步」。
这里的 N 只统计思考过程与工具调用，不含中间的正文段落，
统计口径对应「执行了几项操作」，而非「产生了几段文字」。

点击该行可展开，再次点击则收起。

### 工具调用

工具卡片在折叠状态下只占一行，右侧显示部分参数，便于快速判断当前操作内容。
展开后可查看完整参数与输出。输出过长时会被截断，末尾标注「（输出过长，已截断）」。

### 智能体交付的文件

智能体把文件发给你时，回合末尾会单独列出文件卡片，每行显示缩略图、文件名、
完整路径与「已发送」，与 QwenPaw 网页版一致。图片可以点开全屏查看，支持双指缩放。
同一回合里重复发送的同一个文件只列出一次。

文件卡片不受「智能体消息折叠」设置影响，即使过程被折叠也会显示。
非图片类型只显示文件名与路径，客户端不代为下载；需要取回时，
请到该路径所在的服务端工作区目录中查找。

### 长消息

自己发送的消息若超过 6 行或 420 字，默认只显示前几行，末尾提供「展开全文」，
展开后可以再次收起。

助手回复不采用这种折叠方式。正文本身就是需要阅读的内容，
折叠反而会破坏 Markdown 的排版结构。

## 4、语音输入

语音识别完全在手机本地完成，音频不会上传，也不需要联网。

### 先下载模型

语音输入**必须**依赖本地识别模型，没有模型就无法使用，这不是可选增强。

在设置中进入「语音输入」，下载识别模型。模型约 150MB，只需下载一次。
下载完成后音频只在本机处理，不再需要联网。

### 麦克风按钮的显示条件

「显示语音按钮」开关默认开启。麦克风是否出现**只看这个开关**，
与模型是否下载无关。

模型未下载时按钮仍然显示，只是颜色偏淡。点击它会弹出提示，
说明需要先下载模型，并提供「去设置下载」的入口。若在这里选择「关闭」，
应用会再问一次是否顺带隐藏语音按钮——「这次不用」与「以后都不显示」是两件事。

### 两种触发方式

设置中可选择的触发方式有两种：

- **点一下**（默认）：点击麦克风开始录音，再次点击结束。
- **按住说话**：按住不放持续录音，松开结束。按住期间手指在屏幕上如何移动都不会中断，
  只要不离开屏幕即可继续录音。

选择「点一下」时，下方会多出一个「说完自动停止」开关。打开后，识别到停顿即自动结束，
无需再次点击。选择「按住说话」时不显示该开关，因为松开本身就表示结束。

单次录音最长 90 秒，到时自动结束。

## 5、字体与外观

### 两类字号分别调整

在设置中进入「外观」，可以看到两个滑块：

- **界面字号**：影响标题、按钮、列表等界面元素。
- **聊天字号**：仅调整对话正文，可单独放大。

两者的可调范围都比较大，界面字号可调到较小或较大，聊天字号的范围更宽。
调大聊天字号时，顶栏与输入框保持原有字号，不会随之放大。

「聊天字号」一行右侧有「预览」。点开后是一个示例聊天页，其中包含用户气泡、
助手气泡、公式与代码三种内容，便于观察不同字号下的实际效果。
预览页底部原本是输入框的位置，换成了一条字号滑块，拖动即可调整，数值同步写回设置。
预览页的说明行写明「只影响对话正文。顶栏与输入框不随字号变化」。
「预览」左侧的「重置」把聊天字号恢复到 100%。

### MiSans 字体

在设置中进入「外观」，可找到「使用 MiSans 字体」。该开关默认关闭；
字体未下载时开关呈灰色且不可点击。

需先点击下方的「MiSans 字体包」完成下载，约 16MB。下载完成后开关才可使用。

字体版权归小米科技有限责任公司所有，遵循 MiSans 许可协议。
应用不随安装包附带字体文件，仅在用户主动点击时从 GitHub 下载。

### 其它外观选项

- **深浅色**：默认跟随系统，也可在设置中手动切换。
- **对话列表紧凑排版**：只显示名称和时间，一屏可显示更多对话。
- **生成中保持屏幕常亮**：长时间生成时避免息屏打断查看。

### 设置页的分组会收起

设置页分为服务器实例、外观、头像、消息显示、通知与行为、语音输入、运行日志、关于八组。
其中「语音输入」与「运行日志」默认收起，点击标题行即可展开或收起。

收起时标题行右侧会显示一句概览，例如「已开启 · 模型已就绪」或「已关闭」，
不展开也能确认当前状态。你的展开状态会被记住，下次打开应用时保持原样。

### 头像

在设置中进入「头像」，可分别为「我的头像」与「智能体头像」选择图片。

- 选中静态图片后会进入裁剪页：双指缩放、单指拖动，白色方框内就是最终显示的区域，
  点右上角「保存」。图片会压到 500×500，占用很小。
- 选中 GIF 动图时不会进入裁剪页，而是直接保存。头像会按原有帧率循环播放。
  动图不裁剪、不缩放，建议选用正方形、边长不超过 500 像素的 GIF，
  否则会按圆形裁掉四周。
- 没有设置头像时，头像位置显示昵称首字与一个底色圆，同一个名字颜色固定。
- 点「移除」可恢复为首字圆。头像只存在手机上，不会上传，也不会随实例同步。

### 使用 QwenPaw 服务端头像

如果你在 QwenPaw 网页端设置过头像，可以在「头像」里打开「使用 QwenPaw 服务端头像」，
手机上就会显示同一张图。这个开关默认开启。

规则只有两条：

- **本机头像优先。** 只要你在这台手机上选过图片，就显示本机这张，服务端的图不会被用上。
  点「移除」之后才会回落到服务端头像。
- **关掉只是不显示。** 关闭开关后回落到昵称首字，但不会删除已下载的图，
  再次打开时无需重新下载。

开关下方有一行「服务端头像」，显示当前是否取到了服务端的图。这一行只做展示：
网页端设置的头像需要在网页端修改，客户端不提供删除入口，避免让人以为两边都要删一次。

服务端头像缓存到手机上，冷启动和断网时也能显示上一次的图。它只用于你自己的头像，
智能体头像仍然在手机上单独设置。

### 我的昵称

「头像」分区下方有「我的昵称」，这个昵称显示在你自己发出的每条消息头部。

默认是「我」。改成别的名字后立即生效，返回聊天页即可看到历史消息的头部也一并变化。
输入框留空则回到默认的「我」。输入时逐字保存，不需要额外的确认或失焦操作。

### 运行日志

设置中进入「运行日志」。这一项默认关闭。

打开后，应用会记录本次运行期间的事件：网络请求、对话流建立与中断、
界面操作、存储读写与语音识别。关闭后不再写入，已有记录保留，仍可查看与导出。

- **记录类型**：可以只保留关心的类别，排查连接问题时关掉其余类别能少很多干扰。
- **查看运行日志**：逐条显示时间、类别、来源与内容。
- **导出运行日志**：保存为文本文件，便于反馈问题时一并提供。
- **导入**：可以载入他人提供的日志文件查看，导入的内容会替换当前显示。

这里记录的是**手机上的客户端事件**，与 QwenPaw 服务端的日志分开记录。
服务端日志要在 Web 控制台查看。日志中的令牌会在写入前替换为星号。

## 6、用量

聊天页顶栏有一个胶囊状指示器，显示上下文占用百分比，点击后可查看明细。

明细中包含总量与进度条。各条消息的占比按字符数估算，界面上标注为「估算」，
并非服务端提供的精确数值。服务端只提供整轮的用量数据，没有按消息拆分的结果。

「用量统计」是另一个入口，可按时间范围与模型查询 token 用量，页面为只读。

设置中的「在回复末尾显示用量」开关默认关闭。打开后，每轮回复的最后一条消息下方
会多出一行，例如「输入 13753 · 输出 73 · qwen3-max tokens」。
数字是这一轮的总量，因此一个回合只在末尾出现一次。
服务端不提供「首字耗时」，应用不显示该指标。

## 7、常见问题

### 无法连接

首先确认端口是否正确，其次确认服务端是否以 `--host 0.0.0.0` 启动。
若服务端只监听 `127.0.0.1`，手机无法访问。

若实例配置了多个地址，可以先点「验证连接」。它会按顺序逐个尝试，
并在结果里说明最终用的是哪一条。若提示「已回退到 …」，说明前面的地址当时不可达。

只填域名时，内网地址按 http 尝试，公网域名按 https 尝试。如果服务端只能通过
http 访问，请把地址写成 `http://…`；如果提示改用 https，则说明该地址只接受
加密连接。协议写错时，界面上可能表现为登录失败或找不到接口，而不是连接失败，
此时请优先核对这一步。

### 顶栏显示「连接中断」

点击这一行即可重新连接。网络恢复后应用也会自行重载，不必重启应用。
若长时间仍然连不上，请确认服务端是否还在运行。

### 出门后连不上，在家正常

这类情况通常是局域网地址在家里可用、在外面不可用。给不在家的场景加一条
VPN 或隧道地址，并在「使用时机」里选「VPN 时优先」，应用会在检测到 VPN 时
优先使用它。当前无法按 WiFi 名称自动切换时，也可以在实例卡片上手动「选择地址」。

### 滑动不顺畅

请确认安装的是正式版安装包。调试版构建（debug）运行明显较慢，
同一段对话的滚动开销约为正式版的两倍以上；使用调试版时出现卡顿属于预期表现。

### 没有麦克风按钮

先确认设置中的「显示语音按钮」开关是打开的。该开关默认开启，
若曾关闭，重新打开即可。按钮是否显示与模型是否下载无关。

### 点击麦克风只弹提示

这说明本地识别模型还没有下载。按提示进入设置下载即可，
模型约 150MB，下载完成后语音输入立即可用。

### 收不到完成通知

应用进程被系统清理后，不会再发出通知。本客户端不常驻后台，也没有推送通道，
因此只能在应用处于前台或进程存活期间提供提醒。

### 模拟器无法安装

安装包按 CPU 架构分成四个，需下载与模拟器架构一致的那一个。
x86_64 模拟器装 `x86_64` 包，arm64 模拟器装 `arm64-v8a` 包；
装错架构会提示无法安装。

### 图片无法显示

图片通过服务端的 `files/preview` 路径读取，要求服务端能够正常访问工作目录中的文件。
外链图片则直接下载，需要手机能够访问该地址。

## 8、功能边界

以下能力本客户端不提供，提前说明可避免无效查找。

- **服务端管理功能**：智能体配置、技能管理、服务端日志查看均不提供，请在 QwenPaw 的
  Web 控制台中操作。设置里的「运行日志」记录的是本机客户端事件，不是服务端日志。
- **离线自动补发**：断网时草稿会保留，界面也会显示失败提示，
  但恢复网络后不会自动重发，需要点击「重试」。
- **Mermaid 图表渲染**：代码块中的图表以源码形式显示，可直接复制使用。
- **实时推送**：审批状态依靠每 2.5 秒一次的轮询获取，因此存在最多两秒多的延迟。
- **首字耗时**：QwenPaw 服务端不提供该指标。

这些取舍的原因记录在 [protocol.md](protocol.md) 的「已知取舍」一节。

## 9、定时任务

入口在「设置 → 服务端配置 → 定时任务」。列表里每个任务占一行，显示名称、
执行频率和启用开关，下面一行说明下一次执行时间或上次的执行结果。
行尾的「⋯」菜单包含「立即执行」「编辑」「执行记录」「删除」；导入的任务在未审核前
还会多出「审核通过」。导入任务未审核时，该行标「待迁移审核」，
点击开关会被拒绝并提示「需先确认」。

### 新建任务

列表底部的「新建任务」进入表单：

- **基本信息**：填写任务名称，并选择任务类型。「消息内容」直接把一段文字投递出去；
  「Agent」则把请求交给智能体执行。后者需要填写请求内容。
- **调度**：先选「循环」或「一次性」。循环任务提供「快捷」与「自定义」两种写法。
  快捷是一排常用预设，点一下即完成设置；自定义按频率类型逐项选择，
  下方会实时显示生成的 Cron 表达式。需要写预设之外的写法时，打开「直接编辑表达式」，
  表达式会变成可输入的文本框。
- **一次性任务**：选择日期和时间，按需打开「重复执行」并设定每几天的间隔，
  结束方式可以选择无限、截止到某个时间或执行固定次数。
- **投递**：选择目标会话。选择器列出对话名称，并可按名称或会话标识搜索；
  名称取不到时显示会话标识，不会出现空白项。Agent 任务可以打开「静默投递」，
  只执行任务而不把过程推送到频道。
- **高级**：默认收起。包含共用会话、最大并发、超时秒数、错过宽限期，
  以及是否开启工具审批检查、结果是否存入收件箱。

  「结果存入收件箱」有三档：`自动`、`存入`、`不存`。`自动`不是一律存入：
  消息内容类任务按周期执行时默认不存，其余组合默认存。这一档在保存时就被确定下来，
  之后不会随设置变化。任务执行成功才会写进收件箱；执行失败只留在任务历史里，
  超时与投递失败则会另记一条事件。

任务固定按北京时间创建和展示，不跟随手机时区。保存前会检查必填项：
名称为空、消息内容为空、Agent 请求为空都会被拦下。

### 时间对照

若服务端配置的时区与北京时间不同，列表顶部和编辑页会出现一块「时间对照」，
把同一个触发时刻在两地的写法并排列出，例如：

```
北京时间  11-04 09:00（UTC+8）
服务端时区  11-03 20:00（UTC-5）
服务端时区与北京时间不同，任务仍按北京时间执行。
```

已保存的任务显示服务端算出的下一次执行时间；编辑中的草稿在本地按北京时间推算，
自定义写法识别不出时只显示末尾那句说明。

### 工具卡片的操作

聊天页里智能体正在运行工具时，展开工具卡片可以看到操作项：

- 「取消执行」：中断这次工具调用，需要二次确认。
- 「转入后台」：让工具转到后台继续跑，结果稍后送达。
- 「推迟转后台」「延长执行超时」：分别把自动转后台、自动中止的时限延长 30 秒。

卡片标题右侧显示当前状态，可能是「运行中」「已转后台」「已完成」「已取消」。
下面一行小字给出倒计时。工具结束后操作项不再显示，因为服务端只保留一段时间的记录。

工具运行超过约 7.5 秒仍未结束时，卡片会自动展开，不必手动点开就能看到输出。
若你在这之前手动收起过卡片，它不会再被自动展开。
